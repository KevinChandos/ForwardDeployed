## Key Design Decisions
| Decision | Rationale |
|---|---|
| `is_deleted BOOLEAN` instead of `deleted_at TIMESTAMPTZ` | User explicitly specified this column name; all partial unique indexes updated to `WHERE is_deleted = FALSE` |
| `set_updated_at()` trigger defined once in 001, reused by all subsequent files | Avoids duplicate function definitions; trigger is applied per-schema via dynamic DO block |
| Circular FK resolved by deferred ALTER TABLE in 007 | PostgreSQL cannot reference a table that doesn't exist yet; FK patch is clean and idempotent on re-run |
| `author_follows` placed in 002 not 001 | Depends on `catalogue.authors`; must be created after that table |
| All discovery/cart child tables placed in 002 | They all reference `catalogue.books` / `catalogue.book_formats` |
| Execution order: 001 → 002 → 003 → 004 → 005 → 006 → 007 | Every cross-schema FK dependency is satisfied in this order |
